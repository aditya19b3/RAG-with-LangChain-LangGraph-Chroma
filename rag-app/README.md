# RAG App

This project provides a starter structure for a Retrieval-Augmented Generation application using LangChain, LangGraph, and Chroma.

## Structure

- src/loaders: document loading utilities
- src/splitters: text chunking strategies
- src/embeddings: embedding generation
- src/vectorstore: vector database integration
- src/retrievers: retrieval logic
- src/prompts: prompt templates
- src/chains: LangChain chains
- src/graph: LangGraph workflow
- src/routes: API routes
- src/services: application services
- src/utils: shared helpers

## Getting started

1. Install dependencies with `npm install`
2. Copy `.env` and add your API keys
3. Run the app with `npm run dev`
